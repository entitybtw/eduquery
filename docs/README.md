# Документация eduquery

eduquery — локальная панель для анализа учебных данных с помощью языковой модели. Один процесс
Rust, SQLite и `llama-server` на том же сервере: данные не отправляются во внешние API.

## Коротко о приложении

- **Обзор** — сводка по потоку и группам.
- **Ученики** — таблица, карточка, профиль (дата рождения, адрес, семья), импорт и экспорт CSV/JSON.
- **Статистика** — оценки, пропуски, портфолио, поведение, питание, сравнение групп и рейтинги.
- **Анализ ИИ** — разбор ученика, сравнение двух учеников, свободный вопрос, официальная характеристика.
- **Бенчмарки** — сравнение нескольких установленных моделей на одной задаче, история, оценки,
  реальные метрики использования.
- **Модели** — каталог GGUF, докачка, активация, удаление, установка движка llama.cpp.
- **Настройки** — параметры генерации, отдельный системный промпт и few-shot пример.
- **Пользователи** — роли, права и лимиты запросов к ИИ.

## Принципы

1. **Данные остаются локально.** Наружу уходят только запросы за движком и моделями.
2. **Только факты из журнала.** Промпты запрещают модели придумывать сведения; пустые разделы
   должны явно обозначаться.
3. **Системная инструкция и пример — разные вещи.** `system_prompt` задаёт правила, пара
   `example_input` / `example_answer` показывает стиль и структуру.
4. **Демо-данные вымышленные.** Никаких реальных людей, школ, адресов и работодателей.
5. **Всё важное измеряется.** Каждая генерация пишет метрики в `usage_metrics`; бенчмарки
   сохраняют ответы и допускают ручную оценку.
