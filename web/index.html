Формат файла

Одна строка — одна запись. Колонки на русском, порядок любой, лишние можно не заполнять. Обязательно «ID ученика» или «ФИО». «Тип записи»: Домашняя работа, Контрольная работа, Проект, Оценка, Пропуск, Портфолио, Поведение, Питание.

Колонки: ID ученика ФИО Группа Эл. почта Тип записи Предмет Название Дата Балл Макс. балл Оценка Статус Время, мин Пропущено уроков Причина пропуска Уважительная Категория Уровень / оплата Комментарий.

Пользователи и права
Права: view — просмотр данных, analyze — запросы к ИИ, import — загрузка таблиц, export — скачивание таблиц, models — модели, движок и параметры генерации, users — управление пользователями. Лимиты считаются по запросам к ИИ за скользящий час и за 24 часа.
